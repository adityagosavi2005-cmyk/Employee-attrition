# Employee Attrition Prediction System

## Overview

Employee Attrition Prediction System is a Machine Learning project that predicts whether an employee is likely to leave the organization based on HR-related factors such as job role, salary, work experience, job satisfaction, and other employee attributes.

The project aims to help organizations identify employees at risk of attrition and support data-driven retention strategies.

---

## Features

* Employee attrition prediction using Machine Learning
* Data preprocessing and feature engineering
* Interactive web interface built with Streamlit
* Real-time prediction based on user inputs
* Model evaluation and performance analysis

---

---

## Dataset

The project uses an employee attrition dataset containing employee demographic, professional, and workplace-related information.

Sample features:

* Age
* Department
* Job Role
* Monthly Income
* Years at Company
* Job Satisfaction
* Work-Life Balance

Target Variable:

* Attrition (Yes / No)
